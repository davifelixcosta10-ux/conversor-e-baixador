O que tem dentro

Dúvidas rápidas

Preciso instalar algo no Linux?

O Conversor usa ffmpeg, ImageMagick, poppler, ghostscript e 7z. O Baixador já vem com o yt-dlp embutido. O instalador avisa o que falta.

E no Windows?

O instalador instala o Python e o GTK4 pelo MSYS2, copia o app e cria o atalho no menu Iniciar. É a primeira versão pra Windows — se algo falhar, abre uma issue no GitHub.

Por que meu WebM não fica em loop no mpv?

WebM e MP4 não carregam marcação de repetição. Use GIF ou WebP animado: os dois têm loop infinito gravado no arquivo.

Os apps mandam meus arquivos pra algum lugar?

Não. Só o contador de downloads desta página registra um número (qual app e qual sistema), sem IP e sem cookie.
